# Adult lab result pathways (verified 11 October 2026)

These routes use the existing observation → governed recommendation → confirmed decision → dated plan chain. A write returns its new recommendations with actions and provenance. The patient screen presents these automatically after entry. Closing the suggestions leaves them in the Overview / visit decision list; it does not decline them. Medicine starts and holds require confirmation.

| Route | Trigger and suggested care | Reference |
| --- | --- | --- |
| Vitamin D | Verified 25-OH D <25 nmol/L (ng/mL ×2.5), UK low-status definition. Check calcium, kidney / stone / granulomatous concerns and supplements. New deficiency: checked, bounded replacement prescription and an explicit course-end date. Completed replacement: 800 IU daily maintenance can be proposed and confirmed. No automatic loading prescription or universal 30 ng/mL target. | [NICE PH56](https://www.nice.org.uk/guidance/ph56/chapter/glossary), [Endocrine Society 2024](https://www.endocrine.org/clinical-practice-guidelines/vitamin-d-for-prevention-of-disease), [NHS dosing](https://www.nhs.uk/medicines/colecalciferol/how-and-when-to-take-colecalciferol/), [SPS safety](https://sps.nhs.uk/articles/safety-considerations-when-using-vitamin-d/) |
| Anaemia | Adult Hb <13 g/dL male / <12 female prompts cause review; <8 g/dL or bleeding / instability needs urgent assessment. WHO 2024 adult cutoff tables cover 15–65; older adults use the BSG adult definition and clinician interpretation. Pregnancy / breastfeeding uses specialist dosing. Confirmed iron deficiency: ferrous sulfate 200 mg (~65 mg elemental iron) daily, response review within 4 weeks. HF iron deficiency uses one cause / IV-iron assessment instead of a second iron alert; IV dosing requires symptoms, product, weight and Hb review. No automatic transfusion or empiric iron for every anaemia. | [WHO 2024](https://www.who.int/publications/i/item/9789240088542), [BSG guideline, reviewed 2026](https://www.bsg.org.uk/clinical-resource/guidelines-iron-deficiency-anaemia-in-adults/), [ESC HF 2023 update](https://academic.oup.com/eurheartj/article/44/37/3627/7246292) |
| Liver enzymes | Actual ALT / AST report upper limits required. Elevation prompts cause / symptom review. On statin, ≥3× ULN proposes pause / dose review; below 3× ULN continue with 4–6-week repeat. Jaundice, confusion, bleeding or illness prompts same-day review. Missing limits cannot authorize a lab-based statin hold. | [ESC/EAS 2019 Table 13, page 43 of PDF](https://eas-society.org/wp-content/uploads/2022/05/2019_EAS-ESC_Guidelines_dyslipidaemia_ATH.pdf), [2025 focused update](https://www.escardio.org/guidelines/clinical-practice-guidelines/all-esc-practice-guidelines/dyslipidaemias/), [SPS liver interpretation](https://sps.nhs.uk/articles/assessing-liver-function-and-interpreting-liver-blood-tests/) |
| CK on statin | Actual report ULN required. >10× ULN: stop proposal, urgent renal / muscle assessment and CK review every 2 weeks. ≥4× to <10×: symptoms → pause, asymptomatic → monitor in 2–6 weeks. <4×: symptom monitoring, pause if symptoms persist. Review exertion, interactions, thyroid and recovery / alternative lipid treatment. No routine CK screening without symptoms or automatic rhabdomyolysis diagnosis. | ESC/EAS Table 13 above; the 2025 focused update complements the existing safety guidance. NHS SPS's alternative >5× stop threshold is not mixed into the ESC default. |

All relative follow-up choices expose a manual date and the confirmation shows exact dates. Equivalent timely bookings are reused, and results close only checks whose due date has arrived. Preliminary and withdrawn values never supply these pathways' treatment context. Actual upper limits are normalized with the result's units, versioned on correction, and never backfilled from a catalogue default. Legacy amiodarone / dronedarone / bosentan liver checks also use actual report limits.

The new vitamin D / oral iron catalogue entries use generic names. A local brand and availability have not been verified; no trade name is invented. The vitamin D replacement prescription remains a clinician task rather than a loading-dose medicine start. Recommendations are generated at saving, after the values are validated and committed.

Source access: primary ESC/EAS PDF fully retrieved; NICE and BSG definitions / dosing verified via their indexed official pages and the BSG publication. Some full HTML pages block automated access. No content copied wholesale.
