# Stage 5 secondary prevention clinical review pack

Every candidate is version 1 and guarded by `governance.stage5_licensed_tested_reviewed == <rule ID>`. Exact recommendations, thresholds, timing, class and level have not been authored or approved. Machine status is `draft`; lifecycle queue state is `CLINICAL_REVIEW`; test status is `not_run`; nothing in this pack is executable.

Evidence baselines are the [2025 ESC/EAS dyslipidaemia focused update](https://www.escardio.org/news/news-room/congress-news/2025-focused-update-dyslipidaemias/), the [2026 ESC cardiac rehabilitation guideline](https://www.escardio.org/guidelines/clinical-practice-guidelines/all-esc-practice-guidelines/cardiac-rehabilitation/), and the [2024 ESC chronic coronary syndromes guideline](https://www.escardio.org/guidelines/clinical-practice-guidelines/all-esc-practice-guidelines/chronic-coronary-syndromes/). CardioFlow does not numerically convert Lp(a) mass and molar units.

| Rule ID                   | Clinical question                                        | Required inputs                                                  | Exclusions / stop conditions                               | Proposed output                  | Evidence; boundary tests                                                          |
| ------------------------- | -------------------------------------------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------- | -------------------------------- | --------------------------------------------------------------------------------- |
| `cad.lipid-review`        | Does lipid therapy need a reviewed intensification plan? | LDL-C; unit; baseline; CAD/ACS; medication; tolerance; adherence | Unknown unit; unverified result                            | Clinician lipid review           | 2025 lipid update; post-ACS; unknown adherence; statin intolerance; unit mismatch |
| `cad.lpa`                 | How should Lp(a) be documented and used?                 | Lp(a); unit; risk context                                        | Unit missing; unsupported conversion                       | Risk-context review              | 2025 lipid update; mg/dL; nmol/L; no result; no numeric conversion                |
| `cad.rehabilitation`      | What rehabilitation referral and follow-up are needed?   | ACS/PCI/CABG; eligibility; barriers; referral; planned start     | Declined with documented reason; ineligible with rationale | Dated rehabilitation task        | 2026 rehabilitation; post-PCI; CABG; barrier; participating                       |
| `cad.prevention-followup` | Which prevention gaps are actionable now?                | Lipids; BP; smoking; diabetes; CKD; rehabilitation; medication   | Already reviewed; not applicable                           | Integrated dated prevention plan | 2024 CCS; multiple gaps; stable patient; post-ACS; unknown dates                  |

The current implementation records clinician-authored plans and exact dates, reuses shared laboratory and medication data, and exposes missing data. It does not autonomously select or dose therapy.
