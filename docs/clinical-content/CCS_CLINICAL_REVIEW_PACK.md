# Stage 5 CCS and ANOCA/INOCA clinical review pack

Every candidate is version 1 and uses the blocked guard trigger `governance.stage5_licensed_tested_reviewed == <rule ID>`. Proposed clinical logic is intentionally absent until an independent reviewer extracts and authors it from licensed evidence. Class/level is not assigned. Machine status is `draft`, lifecycle queue state is `CLINICAL_REVIEW`, test status is `not_run`, and no output is executable.

Primary evidence: [2024 ESC chronic coronary syndromes guideline](https://www.escardio.org/guidelines/clinical-practice-guidelines/all-esc-practice-guidelines/chronic-coronary-syndromes/), version/year 2024. CardioFlow stores metadata and independently authored contracts, not copied guideline tables.

| Rule ID                     | Clinical question                                                   | Required inputs                                                                | Exclusions / stop conditions                              | Proposed output                                  | Boundary tests                                                        |
| --------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------- | ------------------------------------------------ | --------------------------------------------------------------------- |
| `cad.ccs-likelihood`        | What current risk-factor weighted clinical likelihood is supported? | Age; sex; symptoms; risk factors; prior testing                                | Known obstructive CAD; ACS presentation                   | Likelihood review with provenance                | Low likelihood; higher likelihood; missing risk factors; previous CAD |
| `cad.ccs-test-selection`    | Which diagnostic options fit this patient and prior testing?        | Likelihood; symptoms; CCTA; functional imaging; angiography; test quality      | A recent adequate test already answers the question       | Testing options and missing data                 | Recent CCTA; no prior test; poor-quality test; no testing selected    |
| `cad.ccs-antianginal`       | What antianginal optimization merits review?                        | Symptoms; heart rate; BP; LVEF; rhythm; current medication; tolerance          | No symptoms; therapy already reviewed as optimized        | Medication review without automatic prescription | Low BP; bradycardia; HFrEF; refractory symptoms                       |
| `cad.ccs-revascularization` | When should anatomy and clinical factors reach a Heart Team?        | Anatomy; ischemia; LVEF; diabetes; surgical risk; valve status; preference     | Insufficient anatomy; no decision currently required      | Options and missing factors                      | Left main; multivessel; severe AS; uncertain anatomy                  |
| `cad.anoca-inoca`           | Could persistent symptoms reflect ANOCA or INOCA?                   | Angina; ischemia testing; non-obstructive anatomy; coronary functional testing | Obstructive culprit lesion; alternative cause established | Mechanism assessment                             | ANOCA; INOCA; vasospasm; microvascular disease; unknown mechanism     |

Review completion requires expected outputs for all boundaries, evidence permission, independent maker/checker approval, a passing independent clinical test run, and explicit publication. The current module supports documenting uncertainty and mechanism assessment without diagnosing or recommending therapy autonomously.
