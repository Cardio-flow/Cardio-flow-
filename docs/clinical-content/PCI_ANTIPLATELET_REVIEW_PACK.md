# Stage 5 PCI and antiplatelet clinical review pack

Every candidate is version 1. The only stored trigger is the impossible non-clinical guard `governance.stage5_licensed_tested_reviewed == <rule ID>`. Exact clinical logic, duration, thresholds, exclusions, class and level remain unassigned until independent review. Machine status is `draft`; lifecycle queue state is `CLINICAL_REVIEW`; technical test status is `not_run`; no candidate is executable.

Primary evidence: [2023 ESC acute coronary syndromes guideline](https://www.escardio.org/guidelines/clinical-practice-guidelines/all-esc-practice-guidelines/acute-coronary-syndromes/), version/year 2023. No proprietary risk-score implementation or copied guideline algorithm is included.

| Rule ID                        | Clinical question                                                 | Required inputs                                                        | Exclusions / stop conditions                                          | Proposed output                                      | Boundary tests                                                        |
| ------------------------------ | ----------------------------------------------------------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------- | ---------------------------------------------------- | --------------------------------------------------------------------- |
| `cad.dapt-review`              | Does the antiplatelet plan fit ischemic and bleeding context?     | ACS/CCS; PCI date; stent; bleeding; CKD; age; medication; surgery      | Active major bleed needs direct review; medication record unconfirmed | Dated clinician review                               | ACS PCI; CCS PCI; bleeding; surgery                                   |
| `cad.pci-anticoagulant`        | Is combined antiplatelet and oral anticoagulant therapy coherent? | OAC indication; aspirin; P2Y12; combination dates; bleeding; PCI       | OAC indication unverified                                             | Combined-therapy review                              | AF plus PCI; no OAC; major bleed; unknown dates                       |
| `cad.bleeding-risk`            | Which validated bleeding-risk assessment is applicable?           | Haemoglobin; renal function; age; prior bleeding; OAC; procedure       | Missing criterion; population mismatch                                | Transparent risk assessment                          | Complete ARC-HBR inputs; incomplete PRECISE-DAPT inputs; recent bleed |
| `cad.p2y12-switch`             | Does a P2Y12 switch require a documented strategy?                | Current agent; reason; ACS; PCI; bleeding; interactions                | No switch planned                                                     | Clinician switching review                           | Intolerance; bleeding; surgery; unknown prior dose                    |
| `cad.staged-revascularization` | Does residual disease need staged revascularization review?       | Culprit PCI; residual lesions; HF; diabetes; valve disease; preference | No residual disease; unstable context requires separate pathway       | Heart Team or staged-plan review                     | Multivessel STEMI; left main; severe AS; no residual disease          |
| `cad.stent-complication`       | Do recurrent symptoms after PCI require urgent assessment?        | PCI timing; symptoms; ECG; troponin; hemodynamics; adherence           | No compatible symptoms; data entered in error                         | Urgent clinician review without autonomous diagnosis | Early concern; later restenosis concern; alternative diagnosis        |

The implemented data layer already links aspirin, a P2Y12 agent, an oral anticoagulant, combination start/end, exact review date, bleeding context, ischemic context, PCI, lesion and stent. A new bleeding or stent-thrombosis concern supersedes the old plan into an uncertain reassessment state and creates a task; it never stops medication automatically.
